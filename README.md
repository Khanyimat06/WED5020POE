# Khanyisani's Skin Care 🧴✨

A fully responsive, interactive front-end website for **Khanyisani's Skin Care**, a proudly South African skincare brand based in Pretoria. This project was built to showcase products, allow customer enquiries, and provide essential business information. 

## 📖 About the Project
This website serves as a digital storefront for Khanyisani's Skin Care. It features a clean, warm aesthetic (using beige and gold tones) that reflects the brand's identity of "bringing light to your skin." It includes interactive product filtering, a contact map, form validations, and smooth scrolling animations.

## 🚀 Features
* **Responsive Design:** Works seamlessly on desktop, tablet, and mobile devices using CSS Grid and Flexbox.
* **Dynamic Pricing & Filtering:** Users can search, filter by category, and sort products dynamically without the page reloading (built with Vanilla JS).
* **Form Validation:** The Enquiry and Contact forms include real-time validation for names, emails, and South African phone numbers.
* **Google Maps Integration:** The contact page features an embedded Google Map showing the store location.
* **Interactive UI:** Includes scroll-reveal animations, a back-to-top button, and a custom image lightbox (full-screen gallery viewer).
* **Accessibility:** Built with semantic HTML, ARIA labels, and keyboard navigation support.
